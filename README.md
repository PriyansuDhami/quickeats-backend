# quickeats-backend
Scalable food delivery backend built with FastAPI, PostgreSQL, Redis, RabbitMQ, and Docker.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Redis
- RabbitMQ
- Docker
- Pytest

## Features

- JWT authentication
- Restaurant and menu management
- Cart management
- Order processing
- Redis caching
- Asynchronous event processing
- Idempotent order handling
- Dockerized services
- Automated testing
